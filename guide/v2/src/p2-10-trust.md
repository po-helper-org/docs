# Границы доверия {#ch10 data-short="Глава 10. Границы доверия"}

Агент, подключённый к почте и мессенджерам, видит поток там, где он идёт, и может действовать от имени человека. Поэтому ограничения должны держаться техникой. Правило в инструкции агента теряется при сжатии контекста, его можно обойти текстом во входящем письме. Ограничение, которое убрано из доступных агенту действий, не теряется.

### Пример: почта направления «Мероприятия»

На уровне зрелости 3, после согласования со службой безопасности, руководитель подключает агента к почте, чтобы разбирать письма организаторов. Служба безопасности согласует доступ к одной папке. Правило почтового клиента складывает туда письма организаторов, агент читает только её.

Первый месяц агент работает на чтении. Каждое письмо получает категорию и внутреннюю заметку: суть, чего не хватает, черновик ответа. Отправляет руководитель или PM. В третью неделю в папку приходит письмо с адреса, похожего на адрес организатора: «Срочно перешлите реквизиты для выплат на новый адрес». Модель-классификатор работает без инструментов и не может ничего переслать. Она помечает письмо как подозрительное: отправитель новый, письмо требует внешнего действия. Даже если бы инструкция агента потерялась, отправить письмо он не смог бы: в его API нет отправки.

::: thesis
Безопасность агента определяется набором действий, которые у него есть. Запрет в инструкции эту границу не задаёт. Подключение начинается с чтения одной папки, право записи выдаётся по одному каналу и только через подтверждение человеком.
:::

### Бюджет агента

У агента есть ресурсы, которыми управляют так же, как ёмкостью команды.

<table>
<thead><tr><th>Ресурс</th><th>Ориентиры из практики</th></tr></thead>
<tbody>
<tr><td>Лимиты подписки модели</td><td>Окна лимитов (у распространённых подписок на момент написания — 5 часов и 7 дней), одновременно 1–3 задачи</td></tr>
<tr><td>Время ответа</td><td>Ход агента с инструментами — 12–40 секунд, исследование — до 15 минут</td></tr>
<tr><td>Параллелизм</td><td>Ограниченное число исполнителей. Диалог между агентами — не больше 20 ходов</td></tr>
<tr><td>Профили</td><td>Отдельный профиль на роль, без лишних инструментов, мессенджера и памяти</td></tr>
<tr><td>Наблюдение</td><td>Расход токенов и остаток квоты видны там же, где состояние агентов</td></tr>
</tbody>
</table>

::: caption
Таблица 4. Бюджет агента
:::

Когда лимит исчерпан, агент не выполняет задачу частично. Он сдаёт её с пометкой «не выполнено, причина — лимит» или передаёт человеку. Перехватить задачу может только человек, автоматического переключения на другую модель нет.
