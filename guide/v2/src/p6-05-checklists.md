# Чек-листы {#app-e data-short="Приложение E. Чек-листы"}

::: checklist
### E.1. Десять дней подготовки (глава 12)

- Замерена базовая линия прошлого квартала: часы на отчёты, сдвинутые даты, за сколько дней узнавали о проблемах, сколько раз спрашивали «как дела»
- Руководитель подтвердил критерии оценки квартала
- Потоки распределены по режимам, личный контроль — один поток
- Собрана память агента, ставки заведены по потоку личного контроля
- Проведён разговор с каждым техлидом в рамке обмена
- Заключён контракт с линейным PM
- Назначен хранитель артефактов
- В самой слабой команде — одно обещание, один гейт, одно демо
- Проведена первая сводка красных строк
- Отправлен первый отчёт в новом формате

### E.2. Утренний ритуал (глава 13)

- Статус прочитан до встречи
- Синхронизация — только по красным строкам, цитаты в очереди
- Вчерашние результаты агента приняты или возвращены
- План недели, план дня и список «не делаю»
- Задачи агентам поставлены с полем «как проверим»
- Получено «Договорились» с разделом «Додумал сам»

### E.3. Подключение агента к корпоративным системам (глава 10)

- Доступ согласован со службой безопасности
- Известно, где модель обрабатывает данные
- Права — только чтение, право отправки отложено минимум на месяц
- Ограничен список тех, кто может писать агенту
- Агент не видит учётных данных, запись идёт только через сервис с подтверждением
- Текст писем и сообщений обрабатывается только как данные

### E.4. Переход на следующий уровень зрелости (глава 28)

- В память пишет больше одного человека — для уровня 2
- Лестница прожита и откалибрована хотя бы квартал
- Очередь разбирается стабильно и не копится неделями
- Служба безопасности согласовала чтение потока — для уровня 3
- Есть Product Ops или явный владелец операционной модели

### E.5. Ежемесячная проверка памяти (глава 27)

- 3–7 ставок, у каждой есть срок и зависимости
- Устаревшие узлы не старше двух сроков годности
- Очередь разбирается за неделю
- Есть хотя бы один стык со смежником
- Из десяти случайных записей агента девять проходят проверку источника
