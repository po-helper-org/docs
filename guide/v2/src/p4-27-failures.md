# Где это ломается {#ch27 data-short="Глава 27. Где это ломается"}

Переход ломается в предсказуемых местах. У каждой точки отказа есть признак, который виден за одну-две недели, и действие, которое возвращает систему в рабочее состояние. Добавлять автоматику при сбое не нужно: в большинстве случаев причина в правилах или в привычке.

::: thesis
Ежемесячная проверка памяти занимает полчаса. Ставок 3–7, у каждой есть срок и зависимости. Нет узлов, просроченных больше чем на два срока годности. Очередь разбирается за неделю. Есть хотя бы один стык со смежником. Из десяти случайных записей агента девять проходят проверку источника. Если не выполнены два пункта или больше, руководитель разбирает правила до того, как ставить новые задачи.
:::
