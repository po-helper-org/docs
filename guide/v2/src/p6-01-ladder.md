# Лестница доказательств {#app-a data-short="Приложение A. Лестница доказательств"}

Уверенность считывается по одному вопросу: какой самый сильный артефакт существует и открывается по ссылке? Каркас ступеней одинаков для всех команд. Формулировки под свой домен подбирают один раз в начале квартала и до его конца не меняют. Подробно — глава 6.

Правила: уверенность ставки равна минимуму по её критическим зависимостям; молчание не подтверждение; противоречие снижает уверенность; объём подтверждения записывается всегда.
