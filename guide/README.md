# Гайд для руководителей (PDF)

**«ИИ-агенты в управлении»** — практическое руководство для руководителей, которые внедряют методологию у себя в компании. Собрано из материалов сайта (`docs/paf-product-ops/`, `docs/ai-transformation/`, быстрый старт) и переработано под руководителей.

Готовый файл: [`dist/ai-agents-leaders-guide.pdf`](dist/ai-agents-leaders-guide.pdf) — A4, около 80 страниц, оглавление с номерами страниц, закладки, текст ищется.

## Что получает читатель

| Результат | Часть гайда |
|---|---|
| Как пользоваться ИИ-агентами: память агента, лестница доказательств, гейты, постановка задач и приёмка, карта делегирования, безопасность, быстрый старт | II, главы 5–12 |
| Как поднять личную эффективность: пять системных замен, распределение внимания, десять дней подготовки, утренний ритуал, отчётность, кейсы | III, главы 13–21 |
| Как поднять эффективность команды: недельный артефакт вместо дейликов, разговор про даты, контракт ритуалов, роли PM и хранителя, зависимости, ёмкость, поддержка клиента, команда агентов | IV, главы 22–31 |
| Как может выглядеть трансформация департамента: порядок внедрения, уровни зрелости, роли, общая память, управление без ручных отчётов, конвейер агентов, наблюдаемость, онбординг, дорожная карта, метрики и риски | V, главы 32–41 |

Часть I объясняет «почему» (нагрузка от стыков, ускорение против замены, принципы, три режима). Приложения A–G: лестница, гейты, сроки годности, шаблоны файлов и писем, чек-листы, словарь, источники и лицензия.

## Принципы редактуры

- Аудитория — руководители (PO, руководители продуктов, направлений, департаментов), а не разработчики инструментов: детали реализации внутренних систем организации опущены, оставлены принципы и правила, которые можно перенять.
- Никаких упоминаний конкретной компании-работодателя. Сборка падает, если в тексте встречается запрещённое упоминание (`FORBIDDEN` в `build.py`).
- Имена людей, систем и ключи задач в примерах вымышлены; числа иллюстративные.
- Авторство и лицензия сохранены: производное от PAF (С. Тихомиров) и PAF Product Ops, CC BY-SA 4.0.

## Структура

```text
guide/
  src/          текст гайда в Markdown, собирается по порядку имён файлов
  assets/       схемы (PNG, из docs/paf-product-ops/assets)
  style.css     вёрстка для печати: A4, колонтитулы, оглавление, врезки
  build.py      Markdown → HTML (pandoc) → PDF (WeasyPrint)
  dist/         готовый PDF
```

## Сборка

```bash
pip install weasyprint
```

```bash
python3 guide/build.py
```

Нужен `pandoc` в системе. Результат — `guide/dist/ai-agents-leaders-guide.pdf`.

Врезки в тексте: `::: {.callout .key|.tip|.warn|.example}` с заголовком `[Заголовок]{.callout-title}`. Титульная страница части — блок `::: partpage`. Заголовки `##` попадают в оглавление.
