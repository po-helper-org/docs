# Книга «ИИ-агенты в управлении»

Практическое руководство для руководителей, которые внедряют методику у себя в компании: от работы с ИИ-агентами и личной эффективности до эффективности команды и трансформации департамента.

**Готовая книга:** [`v2/dist/ai-agents-v-upravlenii.pdf`](v2/dist/ai-agents-v-upravlenii.pdf) — A4, 129 страниц, оглавление с номерами страниц, закладки, текст ищется.

## Состав

| Раздел | Главы | Что внутри |
|---|---|---|
| Введение | — | Для кого книга, четыре результата, сквозной пример, маршруты чтения, минимальный путь первого квартала |
| I. Почему старые способы перестают работать | 1–3 | Куда уходит время руководителя, ускорение против замены, модель общей памяти |
| II. Как работать с ИИ-агентами | 4–10 | Память агента, факт и гипотеза, уверенность по доказательствам, гейты, задача агенту, делегирование, границы доверия |
| III. Личная эффективность | 11–18 | Пять замен, десять дней подготовки, утренний ритуал, ритм квартала, отчёт, три кейса |
| IV. Эффективность команды | 19–27 | Записи техлидов, разговор про даты, контракт ритуалов, роли, зависимости, ёмкость, поддержка клиента, команда агентов, точки отказа |
| V. Трансформация департамента | 28–32 | Порядок внедрения, уровни зрелости, роли, общая память, конвейер агентов, дорожная карта и метрики |
| Приложения | A–G | Лестница, гейты и ёмкость, сроки годности, 14 шаблонов, 5 чек-листов, словарь, источники и лицензия |

Вся книга идёт на одном вымышленном сквозном примере — направлении «Мероприятия» в квартале Q4 2026. Числа и даты согласованы между главами.

## Структура каталога

```text
guide/
  v2/                 актуальная версия
    src/              текст по главам: p0 — введение, p1–p5 — части, p6 — приложения
    fonts/            Onest (SIL OFL 1.1)
    style.css         вёрстка
    build.py          Markdown → HTML (pandoc) → PDF (WeasyPrint)
    REFERENCE.md      разбор референсов, визуальная система, правила против слопа
    PLAN.md           план книги и сквозной пример
    dist/             готовый PDF
  src/, dist/, …      первая редакция (v1), сохранена для истории
```

## Сборка

```bash
pip install weasyprint
```

```bash
python3 guide/v2/build.py
```

Нужен `pandoc`. Без аргумента собирается вся книга с обложкой и оглавлением. С аргументом собирается часть: `python3 guide/v2/build.py p3` — только часть III.

## Правила текста и вёрстки

Описаны в [`v2/REFERENCE.md`](v2/REFERENCE.md): визуальная система по образцу аналитических отчётов Cloud.ru (собственный акцентный цвет, открытый шрифт Onest), структура подачи по образцу Shape Up, правила против ИИ-слопа по чек-листу unslop. Сборка останавливается, если в тексте встречается упоминание компании-работодателя.
