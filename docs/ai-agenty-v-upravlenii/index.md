# ИИ-агенты в управлении

Практическое пособие для руководителей: от личной эффективности до трансформации департамента.

[Скачать PDF](ai-agents-v-upravlenii.pdf){ .md-button .md-button--primary download }

Издание 1.0, ноябрь 2026. A4, 134 страницы, около 29 000 слов.

## Что внутри

| Часть | Главы | О чём |
|---|---|---|
| I. Почему старые способы перестают работать | 1–3 | Куда уходит время руководителя, ускорение против замены, модель общей памяти |
| II. Как работать с ИИ-агентами | 4–10 | Память агента, факт и гипотеза, уверенность по доказательствам, гейты, задача агенту, делегирование, границы доверия |
| III. Личная эффективность | 11–18 | Пять замен в неделе, десять дней подготовки, утренний ритуал, отчёт, три кейса |
| IV. Эффективность команды | 19–27 | Записи техлидов, разговор про даты, ритуалы, роли, зависимости, ёмкость, поддержка клиента, команда агентов |
| V. Трансформация департамента | 28–32 | Порядок внедрения, уровни зрелости, роли, общая память, конвейер агентов, дорожная карта и метрики |
| Приложения | A–G | Шкалы, 14 шаблонов, 5 чек-листов, словарь, источники |

Вся книга идёт на одном вымышленном сквозном примере. Имена, системы и числа служат иллюстрацией.
