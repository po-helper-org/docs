# Методология Po-helper

**Обучающие материалы и описание методологии** продуктовой команды нового поколения:
как пройти путь от большой идеи до подтверждённого Product-Channel Fit, объединяя классический
Product Discovery с AI-Native операционной моделью **PAF**.

!!! tip "Начать за три шага"
    Новый проект? Соберите **память агента** — проверяемый контекст, по которому
    ИИ-агенты ориентируются в вашей организации.
    → **[Быстрый старт](quick-start.md)**
