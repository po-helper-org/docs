# Шаг 1. Выбрать уровень зрелости

Уровень определяется не амбицией, а числом людей, пишущих в репозиторий. Полная таблица — на странице [«Уровни зрелости»](../theory/maturity-levels.md): 0 — локальная папка, 1 — личный приватный репо, 2 — командный (CI блокирует merge), 3 — потоковый (автоприём чатов и почты). **Начинайте с уровня 0.** Выше — только когда появился второй человек.

Уровень 0 работает в первый вечер. Пересчёт CP на нём — запрос агенту, а не workflow.

**Про страх имитации:** ручная работа не делает это имитацией. Имитацией делает CP без артефактов. Пять ставок в локальной папке, где каждое число подпёрто ссылкой — рабочая система. Красивый CI поверх чисел из головы — имитация.
