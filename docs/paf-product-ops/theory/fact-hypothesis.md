# 13. Факт, гипотеза, галлюцинация

Факт: есть источник, дата, субъект, можно перепроверить. Гипотеза: источника нет либо источник — мнение. Тест один: покажи, где проверить.

| **Правило** | **Механика** |
| --- | --- |
| Провенанс обязателен | Строка без ссылки — не факт, какой бы уверенной ни была формулировка |
| Агент не создаёт факты | Три операции: перенести с источником, посчитать по правилам, указать на пустоту |
| CP выводится, не назначается | Модель применяет правило, а не выносит суждение. Галлюцинировать нечего |
| Противоречие снижает CP | Система не выбирает правильный источник — расхождение и есть неопределённость |
