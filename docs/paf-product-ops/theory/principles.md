# 4. Шесть принципов PAF

Методология строится на шести принципах. Дальше вся механика — их следствие, поэтому стоит прочитать их до того, как разбираться в терминах.

| **Принцип** | **Формулировка** | **Как реализуется** |
| --- | --- | --- |
| 1. Прозрачность до очевидности | Функция менеджера — сокращать время на обмен квантами информации. Уровень доверия к решениям зависит от полноты и непротиворечивости информации и доступа к ней у всех сторон | Нексусы вместо разрозненных документов; отсутствие беклога, в котором непонятно, откуда взялись идеи |
| 2. Совместная унификация контекста | Формализация контекста важнее повторяющейся коммуникации, при которой контекст теряется. Спросите десять человек о ценности продукта — получите десять ответов | Все заинтересованные лица наполняют один Нексус, а не набор документов, прочитанных один раз |
| 3. Гибкая стабильность (Stagility) | Стабильность долгосрочной цели плюс гибкость пути к ней | Долгосрочная стратегия определяет будущее состояние, но не способ достижения. Разрыв между долгосрочным и краткосрочным управляется через риски |
| 4. Управление рисками равно управление знаниями | Управление продуктом — не производство, а возделывание. Вместо потерь оптимизируются риски: потери — прошлое, риски — потенциальное будущее | Задача инженера продукта — сокращать риски, насыщая Нексусы информацией. Это меняет Confidence Point, а он меняет состав банча |
| 5. Скаутинг вместо приоритизации | Нет списка хотелок, который нужно приоритизировать. Есть карта целей и знание из Нексуса | Задача — не сгенерировать побольше идей, а искать возможности и угрозы, пока не останется идея с самым высоким уровнем уверенности |
| 6. Прибыль через ценность | Сначала востребованный продукт и product/market fit, потом масштабируемая монетизация | Метрика mNSM: монетизируемая ценность каждой фичи после запуска |

**Почему это важно для управления рисками:** четвёртый принцип — фундамент всего документа. Риск в PAF не оценивается экспертно, а выражается через уровень знания. Отсюда и вся механика CP, лестницы и распада.
