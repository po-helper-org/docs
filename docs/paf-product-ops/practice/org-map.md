# Карта репозиториев организации

Организация [po-helper-org](https://github.com/po-helper-org) в октябре 2026 прошла аудит: 65 репозиториев сведены в пять групп. Здесь — карта и принципы порядка, чтобы её можно было повторить в своей организации. Подробности по каждой группе — в соседних страницах раздела.

## Пять групп

| Группа | Что внутри | Видимость | Где описано |
|---|---|---|---|
| **Методология** | Сайт `docs`; Кортекс `poh-cortex`; `research-as-investment`; `po-agent` | Публичные | Эта методология |
| **Навыки и агенты PO** | `poh-okr-agent`, `poh-bft-writer`, `poh-sprint-agents`, `poh-backlog-skills`, `poh-morning-status`, `poh-dev-daily`, `poh-sysreq-agent`, `poh-memory-engine` | Публичные | [Контур производства](production-contour.md), [утренний конвейер](morning-pipeline.md) |
| **Контур производства** | `poh-issue-agents` («Коробка БФТ»), `poh-howtodemo-agent`, `poh-pr-agents`, `poh-demo-checkout`, замороженные стадии релиза и разработки | Публичные | [Контур производства](production-contour.md) |
| **Серверный контур PO** | Виджеты Element, мост к агентам Hermes, мосты каналов связи, корпоративный браузер, почта, поддержка клиентов, наблюдаемость, инфраструктура сервера, день PO | Приватные | [Обещания](promises.md), [доска агентов](agent-board.md), [почта и лента](mail-and-feed.md), [наблюдаемость](observability.md) |
| **Архив** | Заменённые и не используемые репозитории | Только чтение | Ниже |

## Серверный контур по назначению

| Назначение | Репозитории |
|---|---|
| Обещания и заметки | `poh-widget-inbox` |
| Доска задач агентов, приёмка | `poh-widget-harness`, мост `poh-hermes-bridge` |
| Отчёты спринта и бизнес-отчёт, чат ИИ-агента | `poh-widget-sprint-observe`, `poh-widget-sprint-business`, `poh-sprint-agent` |
| Трекер, требования | `poh-widget-jira`, `poh-widget-bft` |
| Почта и календарь | `poh-mail-core`, `poh-widget-mail`, `poh-widget-calendar` |
| Каналы связи и лента | `comunager-hub`, `poh-widget-news`, коннекторы мессенджеров (`poh-widget-messenger-connector`, `poh-widget-telegram-connector`, `poh-widget-mtslink-room`) |
| Созвоны | `poh-widget-meet` |
| Платформа виджетов и доступ | `poh-widget-manager`, `corp-link` |
| Поддержка клиентов | `poh-support-desk` |
| Наблюдаемость и сервер | `poh-observability`, `hermes-home-server` |
| Процесс дня PO | `poh-po-day` |

Правило «каждый виджет — свой репозиторий, свой процесс, свой релиз» сохраняется: слияние в монорепозиторий усложнило бы релиз (перезапуск чужого процесса, общие тесты). Вместо этого общие вещи (установщик, правила доступа, проверка каталога) выносятся в общую библиотеку.

## Архив

Репозиторий переводится в архив, когда выполнены все условия: заменён работающим решением; на сервере нет процесса, который на него опирается; нет живых ссылок из других репозиториев. Архив обратим: история и ветки остаются доступны для чтения, ничего не удаляется.

| Репозиторий | Чем заменён |
|---|---|
| `poh-helper` | Монолит-предшественник; разнесён по навыкам и виджетам (не всё перенесено — [расхождения](gaps.md)) |
| `poh-news`, `poh-feed-poc` | Рабочая лента в `comunager-hub` и `poh-widget-news` |
| `poh-po-task`, `poh-mob-commands` | Голосовая заметка и бот календаря в Инбоксе |
| `mts-vpn` | Подключение VPN выполняет отдельный киоск на сервере |
| `sprint-gds`, `sprint-registry` | `poh-widget-sprint-observe`, `poh-sprint-agent` |
| `poh-scheduller-archive-private` | `poh-widget-calendar` |
| `poh-focus-mode-plugin`, `dsh-communication-plugin` | Платформа DeepSeek Harness вытеснена агентами Hermes и виджетами Element |

## Принципы порядка

1. **Одна группа — один принцип видимости.** Публично — методология, навыки и открытые инструменты; приватно — всё, что связано с корпоративными интеграциями. Перед переводом из приватного в публичный выполняется очистка от идентификаторов, имён и адресов.
2. **Прод — слитый коммит.** Работающий сервис не должен опережать главную ветку ([расхождения](gaps.md)).
3. **Профиль организации — карта, а не манифест.** Каждый репозиторий в нём отнесён к группе; несуществующие и архивные убираются.
4. **Лицензия у каждого публичного репозитория.** Производное от PAF — CC BY-SA 4.0.
5. **Реестр портов, команд и юнитов — один**, а не разбросанный по заметкам.
6. **Архив вместо удаления.**
