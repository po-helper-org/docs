# Где практика расходится с методологией

Раздел собран из аудита репозиториев организации (октябрь 2026). Это не жалобы на методологию, а **список улучшений**: что практика уже показала, а текст методологии ещё не отражает, и что инструменты обещают, но не исполняют. Закрытые пункты вычёркиваются; полная сверка — в журнале изменений ([changelog](../changelog.md)).

## Практика опережает текст

| # | Наблюдение | Что сделать |
|---|---|---|
| 1 | «Беклог упразднён» ↔ рабочая система опирается на списки: обещания, доску задач агентов, доски Jira. Это не беклог идей, а реестр **обязательств** | Объект «обещание: заказчик, исполнитель, срок» введён в [практике](promises.md); отразить в словаре |

## Инструменты не исполняют того, что описывает текст

| # | Утверждение методологии | Состояние кода |
|---|---|---|
| 10 | Потолки канала, полномочий, редкого наблюдения | Только текст; кодом проверяются источник и спор |
| 11 | Арифметика достижимости («+1 за две недели против нужных +5») | В скилле как процедура; в коде нет |
| 12 | Пороги гейтов и даты | Поля есть, никакая команда их не вычисляет |
| 13 | 70% ёмкости и 15–20% на выяснение | Рекомендации автора; в инструменте нет |
| 14 | «Неизвестно = high» | Работает только для явно записанного `unknown`; отсутствующее поле берёт значение Нексуса |
| 15 | Три формы обещаний: committed/target; Intent/Target/Commitment; гейты `plan/build/commit` | Три схемы; соответствие в [приложении B](../appendix/gates.md) |
| 16 | Три отчёта «Команда / Агент / Стратегия», кнопки, «Договорились» | Описаны в SPEC; в реализации утреннего брифа формат иной |
| 17 | «Девять команд `/paf-*`» | Реализованы десять навыков другого состава; четыре действия без замены ([приложение E](../appendix/commands.md)) |
| 18 | Распад лестницы нигде не вычисляется для обещаний PO | В Инбоксе — только эвристика «Неактуально» и свежесть отчёта |

## Отступления от правил делегирования

- Методология: отправка сообщений от имени человека во внешние каналы не делегируется, агент готовит только черновик. В одном из контуров (харнесс требований) принято решение допустить автономную переписку с заказчиком в рамках лимита, журнала и кнопки «стоп» (почтовый мост под отдельным пользователем, останов при первом отказе пароля). Это осознанное отступление; его нужно явно записать в методологию либо вернуть к «только черновик».
- Контур производства допускает стадию разработки агентом, тогда как правило R8 протокола говорит «агент не пишет код» ([контур производства](production-contour.md)); README и профиль организации расходятся с реализацией.

## Нарушения принципа «git — носитель истины»

- Часть сервисов работает с кода, которого нет в `main` (весь код одного бота лежит вне главной ветки; несколько PR ждут слияния). **Правило: деплой только из слитого коммита.**
- Хранилище обещаний в Backlog.md не имеет собственного репозитория в организации; для исполнения нужна база, а не git — граница принципа.
- Экземпляр Кортекса на сервере без удалённой копии.
- Две вендорные копии `poh-cortex` в других репозиториях без механизма обновления.

## Разнобой названий и шкал

- Восемь числовых шкал живут одновременно (см. [словарь](../theory/glossary.md#scales)); читателю нужен один раздел, который их разводит.
- Каталог Нексусов описан тремя способами: восемь в методологии, семь в реестре `poh-cortex`, отдельные тринадцать на сайте. Нужен один каталог.
- Термин «ставка» имеет три смысла: единица изменений стратегической линзы (PAF), обещание с порогом (адаптация), само исследование (`research-as-investment`).
- Версия методологии: файл в `docs` — редакция 20, Кортекс ссылается на 22, SPEC дня PO — на 25. Этой публикацией версия единая — [журнал изменений](../changelog.md).
- Сайт `docs` считает CP по ICE и голосованием команды, тогда как методология считывает его с лестницы. Нужно либо привести сайт к лестнице, либо разделить «скоринг гипотез» и «CP обещания».

## Внутренние противоречия

- Шаблон узла потребителя говорит «три и более интервью с записью → 4–5», а потолок канала для устного — 3. Нужно правило: запись интервью с расшифровкой — письменный артефакт, иначе потолок остаётся 3.
- Стартовый репозиторий включает CI и `CODEOWNERS` «с нулевого дня», а памятка минимума говорит их не подключать ([уровни зрелости](../theory/maturity-levels.md)).
