# П6. Квартальный ритм при пяти потоках

| **Каденция** | **Что делаете** | **Сколько времени** |
| --- | --- | --- |
| Ежедневно | Читаете агрегированный список красных строк по всем потокам. Реагируете только на то, где нужна ваша рука | 5 минут |
| Еженедельно | Разбираете артефакты техлидов. Один разговор по потоку, где красное | 40 минут |
| Конец спринта | Разговор про даты по потоку личного контроля. По делегированным — только там, где обещание уходит наружу | 30 минут |
| Середина квартала | Арифметика достижимости по всем пяти. Решение по каждому красному: ресурс, снятие даты или эскалация | 2 часа |
| Конец квартала | Калибровка правил и сборка доказательств | 3 часа |

Итого около трёх часов в неделю на управление пятью потоками против того, сколько уходило на один при ручной сборке статусов. Это и есть источник экономии — не скорость операций, а их количество.
