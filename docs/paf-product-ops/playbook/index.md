# Часть II. Playbook личной трансформации

[Часть I](../theory/index.md) отвечала на вопрос «почему». Эта часть отвечает на «что менять в своей неделе». Она написана под конкретную ситуацию: PO, у которого объём обязательств вырос кратно, а людей не прибавилось. Числа в примерах иллюстративные — подставьте свои.

!!! info "Три слоя материала"
    Теория (Часть I) — про реформу процессов целого IT-департамента. Playbook (Часть II) — про вашу личную трансформацию за один квартал. Практикумы (отдельный сборник, [slides.aleksishmanov.ru](https://slides.aleksishmanov.ru)) — про локальные оптимизации: быстрее собрать требования, быстрее спланировать квартал, охватить больше диалогов, точнее держать сроки. Слои независимы: практикумы работают без Playbook, Playbook работает без согласия департамента.
